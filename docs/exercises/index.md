## Quick Practice: With Preposition S/Se

Put the noun in Instrumental:

### Set 1: Accompaniment

1. Jdu s ___ (bratr) →
2. Mluvím se ___ (sestra) →
3. Bydlím s ___ (rodiče) →
4. Pracuji s ___ (kolega) →
5. Jdu s ___ (kamarádka) →

<details>
<summary>**Answers**</summary>

1. Jdu s **bratrem** (masc. → -em)
2. Mluvím se **sestrou** (fem. -a → -ou)
3. Bydlím s **rodiči** (masc. pl. → -i)
4. Pracuji s **kolegou** (masc. → -em)
5. Jdu s **kamarádkou** (fem. -a → -ou)

</details>

### Set 2: Means & Tools (No Preposition!)

1. Píšu ___ (pero) →
2. Jedu ___ (auto) →
3. Krájím ___ (nůž) →
4. Platím ___ (karta) →
5. Jím ___ (vidlička) →

<details>
<summary>**Answers**</summary>

1. Píšu **perem** (neut. → -em)
2. Jedu **autem** (neut. → -em)
3. Krájím **nožem** (masc. → -em)
4. Platím **kartou** (fem. -a → -ou)
5. Jím **vidličkou** (fem. -a → -ou)

</details>

### Set 3: Location Prepositions

1. Stojím před ___ (dům) →
2. Auto je za ___ (garáž) →
3. Lampa visí nad ___ (stůl) →
4. Kočka je pod ___ (postel) →
5. Sedím mezi ___ (bratr) a ___ (sestra) →

<details>
<summary>**Answers**</summary>

1. Stojím před **domem** (masc. → -em)
2. Auto je za **garáží** (fem. -e → -í)
3. Lampa visí nad **stolem** (masc. → -em)
4. Kočka je pod **postelí** (fem. cons. → -í)
5. Sedím mezi **bratrem** a **sestrou** (masc. -em, fem. -ou)

</details>

## Transformation Drill

Transform from Nominative to Instrumental:

| Nominative | → Instrumental |
|:-----------|:---------------|
| bratr | ? |
| žena | ? |
| auto | ? |
| nůž | ? |
| růže | ? |
| město | ? |

<details>
<summary>**Answers**</summary>

| Nominative | → Instrumental |

| žena | **ženou** |
| auto | **autem** |
| nůž | **nožem** |
