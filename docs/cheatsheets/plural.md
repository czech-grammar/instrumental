# Instrumental Plural Cheatsheet

---

## At a Glance

| Type | Nom. Plural | Instr. Plural | Example |
|:-----|:------------|:--------------|:--------|
| **Masc. hard** | studenti | student**y** | Se studenty. |
| **Masc. soft** | muži | muž**i** | S muži. |
| **Feminine -a** | ženy | žen**ami** | Se ženami. |
| **Feminine -e** | růže | růž**emi** | S růžemi. |
| **Feminine cons.** | věci | věc**mi** | S věcmi. |
| **Neuter -o** | města | měst**y** | S městy. |
| **Neuter -e** | moře | moř**i** | S moři. |

---

## The Main Endings

:::tip Remember These!
| Ending | Used For | Examples |
|:-------|:---------|:---------|
| **-y** | Masc. hard, Neuter -o | studenty, městy |
| **-i** | Masc. soft, Neuter -e | muži, moři |
| **-ami** | Feminine -a | ženami, matkami |
| **-emi** | Feminine -e | růžemi, ulicemi |
| **-mi** | Feminine cons. | věcmi, nocmi |
:::

---

## Masculine Plural

### Hard Stems → **-y**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| student | student**y** | Se studenty. |
| bratr | bratr**y** | S bratry. |
| hrad | hrad**y** | Mezi hrady. |

### Soft Stems → **-i**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| muž | muž**i** | S muži. |
| učitel | učitel**i** | S učiteli. |

---

## Feminine Plural

| matka | matk**ami** | S matkami. |
| škola | škol**ami** | Se školami. |

| Nom. Sg. | Instr. Pl. | Example |

| růže | růž**emi** | S růžemi. |

## Memory Trick

```
┌─────────────────────────────────────────────┐
│           INSTRUMENTAL PLURAL               │
├─────────────────────────────────────────────┤
│                                             │
│   MASCULINE + NEUTER -O:                    │
│   Hard → -Y (studenty, městy)               │
│   Soft → -I (muži, moři)                    │
│                                             │
│   FEMININE:                                 │
│   -A → -AMI (ženami, matkami)               │
│   -E → -EMI (růžemi, ulicemi)               │
│   Cons → -MI (věcmi, nocmi)                 │
│                                             │
└─────────────────────────────────────────────┘
```
