# Instrumental Cheatsheets

Quick visual references for all Instrumental patterns.

---

## The Golden Rule

| Type | Singular | Plural |
|:-----|:---------|:-------|
| **Masculine** | **-em** | **-y/-i** |
| **Feminine -a** | **-ou** | **-ami** |
| **Feminine -e/cons** | **-í** | **-emi/-mi** |
| **Neuter -o/-e** | **-em** | **-y/-i** |
| **Neuter -í** | **-ím** | **-ími** |

:::tip No Palatalization!
Unlike dative, instrumental does NOT change consonants.
matka → matkou (not matce!)
:::
