# Instrumental Singular Cheatsheet

---

## At a Glance

| Type | Nominative | Instrumental | Example |
|:-----|:-----------|:-------------|:--------|
| **Masculine** | student | student**em** | S studentem. |
| **Feminine -a** | žena | žen**ou** | Se ženou. |
| **Feminine -e** | růže | růž**í** | S růží. |
| **Feminine cons.** | věc | věc**í** | S věcí. |
| **Neuter -o** | město | měst**em** | S městem. |
| **Neuter -e** | moře | moř**em** | S mořem. |
| **Neuter -í** | nádraží | nádraž**ím** | S nádražím. |

---

## Masculine → **-em**

| Nom. | Instr. | Example |
|:-----|:-------|:--------|
| student | student**em** | Jsem studentem. |
| bratr | bratr**em** | Jdu s bratrem. |
| pes | ps**em** | Jdu se psem. |
| učitel | učitel**em** | Stal se učitelem. |
| muž | muž**em** | Mluvím s mužem. |
| hrad | hrad**em** | Stojím před hradem. |
| nůž | nož**em** | Krájím nožem. |

:::tip One Simple Ending!
All masculine nouns take **-em** in instrumental singular.
No animate/inanimate distinction like other cases!
:::

---

## Feminine -a → **-ou**

:::tip No Palatalization!
Unlike dative, instrumental does NOT change consonants.
matka → matkou (NOT matce!)
Praha → Prahou (NOT Praze!)
:::

| Nom. | Instr. | Example |
|:-----|:-------|:--------|
| žena | žen**ou** | Se ženou. |
| matka | matk**ou** | S matkou. |
| sestra | sestr**ou** | Se sestrou. |
| kniha | knih**ou** | S knihou. |
| Praha | Prah**ou** | Nad Prahou. |
| vidlička | vidličk**ou** | Jím vidličkou. |
| karta | kart**ou** | Platím kartou. |

---

## Soft Feminine → **-í**

### -e Nouns

| Nom. | Instr. | Example |
|:-----|:-------|:--------|
| růže | růž**í** | S růží. |
| práce | prác**í** | Zabývám se prací. |
| ulice | ulic**í** | Jdu ulicí. |
| restaurace | restaurac**í** | Před restaurací. |

### Consonant-ending Nouns

| Nom. | Instr. | Example |
|:-----|:-------|:--------|
| věc | věc**í** | S věcí. |
| noc | noc**í** | Celou nocí. |
| postel | postel**í** | Pod postelí. |
| garáž | garáž**í** | Za garáží. |

---

## Neuter → **-em** / **-ím**

### -o Nouns → -em

| Nom. | Instr. | Example |
|:-----|:-------|:--------|
| město | měst**em** | S městem. |
| auto | aut**em** | Jedu autem. |
| pero | per**em** | Píšu perem. |
| okno | okn**em** | Oknem. |
| pivo | piv**em** | S pivem. |

### -e Nouns → -em

| Nom. | Instr. | Example |
|:-----|:-------|:--------|
| moře | moř**em** | S mořem. |
| pole | pol**em** | Polem. |
| srdce | srdc**em** | Srdcem. |

### -í Nouns → -ím

| Nom. | Instr. | Example |
|:-----|:-------|:--------|
| nádraží | nádraž**ím** | Za nádražím. |
| náměstí | náměst**ím** | Náměstím. |

```
│   (studentem, bratrem, hradem)              │
│                                             │

│   (ženou, matkou, Prahou)                   │
│                                             │

│   (růží, prací, věcí, nocí)                 │
│                                             │

```
