# Instrumental Singular Endings

The Instrumental singular has relatively simple patterns. Most nouns take **-em** or **-ou**.

---

## The Big Picture

:::tip The Golden Rule
| Gender | Ending | Example |
|:-------|:-------|:--------|
| Masculine (all) | **-em** | studentem, hradem |
| Feminine -a | **-ou** | ženou, matkou |
| Feminine -e/-cons | **-í** | růží, věcí |
| Neuter -o/-e | **-em** | městem, mořem |
| Neuter -í | **-ím** | nádražím |
:::

---

## Quick Reference

| Gender/Type | Nominative | Instrumental | Example |
|:------------|:-----------|:-------------|:--------|
| **Masc. Animate Hard** | student | student**em** | Jsem studentem. |
| **Masc. Animate Soft** | muž | muž**em** | Stal se mužem. |
| **Masc. Inanimate Hard** | hrad | hrad**em** | Jedu za hradem. |
| **Masc. Inanimate Soft** | stroj | stroj**em** | Pracuji se strojem. |
| **Feminine -a** | žena | žen**ou** | Mluvím se ženou. |
| **Feminine -e** | růže | růž**í** | Vůně růží. |
| **Feminine cons.** | věc | věc**í** | S tou věcí. |
| **Neuter -o** | město | měst**em** | Jedu městem. |
| **Neuter -e** | moře | moř**em** | Pluji mořem. |
| **Neuter -í** | nádraží | nádraž**ím** | Jdu za nádražím. |

## Masculine Nouns → **-em**

Both animate and inanimate masculine nouns take **-em** in the instrumental singular.

### Hard Pattern → **-em**

| Nominative | Instrumental | Example |
|:-----------|:-------------|:--------|
| student | student**em** | Jsem studentem. |
| bratr | bratr**em** | Mluvím s bratrem. |
| pes | ps**em** | Jdu se psem. |
| hrad | hrad**em** | Jedu za hradem. |
| dům | dom**em** | Stojím před domem. |
| stůl | stol**em** | Sedím za stolem. |

### Soft Pattern → **-em**

| Nominative | Instrumental | Example |
|:-----------|:-------------|:--------|
| muž | muž**em** | Jdu s mužem. |
| učitel | učitel**em** | Stal se učitelem. |
| stroj | stroj**em** | Pracuji se strojem. |
| nůž | nož**em** | Krájím nožem. |
| lékař | lékař**em** | Stal se lékařem. |

:::tip Simple Rule
All masculine nouns: just add **-em**! No exceptions!
:::

---

## Feminine Nouns

### Hard Feminine (-a nouns) → **-ou**

The ending **-ou** does NOT cause palatalization (unlike dative!).

| Nominative | Instrumental | Example |
|:-----------|:-------------|:--------|
| žena | žen**ou** | Mluvím se ženou. |
| matka | matk**ou** | Bydlím s matkou. |
| sestra | sestr**ou** | Jdu se sestrou. |
| Praha | Prah**ou** | Jedu nad Prahou. |
| kniha | knih**ou** | Píšu pod knihou. |
| banka | bank**ou** | Stojím před bankou. |
| škola | škol**ou** | Za školou je park. |

:::info No Consonant Changes!
Unlike dative, instrumental **-ou** does NOT change consonants:
- matka → matk**ou** (NOT matcou)
- kniha → knih**ou** (NOT knizou)
- Praha → Prah**ou** (NOT Prazou)
:::

### Soft Feminine (-e nouns) → **-í**

| Nominative | Instrumental | Example |
|:-----------|:-------------|:--------|
| růže | růž**í** | Vůně růží. |
| práce | prác**í** | Zabývám se prací. |
| restaurace | restaurac**í** | Stojím před restaurací. |
| ulice | ulic**í** | Jdu ulicí. |

### Consonant-stem Feminine → **-í**

| Nominative | Instrumental | Example |
|:-----------|:-------------|:--------|
| věc | věc**í** | Nezabývej se tou věcí. |
| noc | noc**í** | Celou nocí jsem nespal. |
| kost | kost**í** | Pes si hraje s kostí. |
| postel | postel**í** | Pod postelí je krabice. |

## Neuter Nouns

### Hard Neuter (-o nouns) → **-em**

| Nominative | Instrumental | Example |
|:-----------|:-------------|:--------|
| město | měst**em** | Jedu městem. |
| auto | aut**em** | Jedu autem. |
| okno | okn**em** | Světlo prochází oknem. |
| pivo | piv**em** | Zapíjím to pivem. |
| kino | kin**em** | Jdu za kinem. |

### Soft Neuter (-e nouns) → **-em**

| Nominative | Instrumental | Example |
|:-----------|:-------------|:--------|
| moře | moř**em** | Pluji mořem. |
| pole | pol**em** | Jdu polem. |
| srdce | srdc**em** | Cítím to srdcem. |

### -í Neuter → **-ím**

| Nominative | Instrumental | Example |
|:-----------|:-------------|:--------|
| nádraží | nádraž**ím** | Jdu za nádražím. |
| náměstí | náměst**ím** | Procházím náměstím. |
| stavení | staven**ím** | Za stavením je zahrada. |

## Common Mistakes

:::warning Watch Out!

**❌ Jdu s ženě** (dative ending!)
**✅ Jdu se ženou** (instrumental -ou)

---

**❌ Jedu s auto** (nominative!)
**✅ Jedu s autem** / **Jedu autem** (instrumental)

---

**❌ Stojím před domů** (wrong ending!)
**✅ Stojím před domem** (masc. → -em)

---

**❌ Mluvím s matce** (dative ending!)
**✅ Mluvím s matkou** (instrumental -ou)
:::
