# Instrumental Plural Endings

The instrumental plural has distinct endings for each gender. The key endings are **-y/-i**, **-ami**, and **-emi**.

---

## The Big Picture

:::tip The Golden Rule
| Pattern | Ending | Examples |
|:--------|:-------|:---------|
| Masculine hard | **-y** | studenty, hrady |
| Masculine soft | **-i** | muži, učiteli |
| Feminine -a | **-ami** | ženami, matkami |
| Feminine -e | **-emi** | růžemi |
| Feminine cons. | **-mi** | věcmi |
| Neuter -o | **-y** | městy, auty |
| Neuter -e | **-i** | moři |
:::

---

## Quick Reference

| Gender/Type | Nom. Sg. | Instr. Pl. | Example |
|:------------|:---------|:-----------|:--------|
| **Masc. Hard** | student | student**y** | Se studenty. |

| **Feminine -a** | žena | žen**ami** | Se ženami. |
| **Feminine -e** | růže | růž**emi** | S růžemi. |
| **Feminine cons.** | věc | věc**mi** | S věcmi. |

| **Neuter -e** | moře | moř**i** | S moři. |
| **Neuter -í** | nádraží | nádraž**ími** | S nádražími. |

## Masculine Plural

### Hard Pattern → **-y**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| student | student**y** | Mluvím se studenty. |
| bratr | bratr**y** | Jdu s bratry. |
| pes | ps**y** | Procházka se psy. |
| hrad | hrad**y** | Cesta mezi hrady. |
| stůl | stol**y** | Sedím mezi stoly. |

### Soft Pattern → **-i**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| muž | muž**i** | Setkávám se s muži. |
| učitel | učitel**i** | Pracuji s učiteli. |
| stroj | stroj**i** | Pracuji se stroji. |
| lékař | lékař**i** | Mluvím s lékaři. |

:::tip Hard vs Soft
- **Hard stems** (student, bratr, hrad) → **-y**
- **Soft stems** (muž, učitel, stroj) → **-i**
:::

## Feminine Plural

### Hard Feminine (-a nouns) → **-ami**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| žena | žen**ami** | Mluvím se ženami. |
| matka | matk**ami** | S matkami a otci. |
| sestra | sestr**ami** | Jdu se sestrami. |
| kniha | knih**ami** | Stůl s knihami. |
| škola | škol**ami** | Mezi školami. |

### Soft Feminine (-e nouns) → **-emi**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| růže | růž**emi** | Váza s růžemi. |
| práce | prac**emi** | S různými pracemi. |
| restaurace | restaurac**emi** | Ulice s restauracemi. |
| ulice | ulic**emi** | Mezi ulicemi. |

### Consonant-stem Feminine → **-mi**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| věc | věc**mi** | S těmi věcmi. |
| noc | noc**mi** | Mezi nocmi. |
| kost | kost**mi** | Pes si hraje s kostmi. |

---

## Neuter Plural

### Hard Neuter (-o nouns) → **-y**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| město | měst**y** | Cesta mezi městy. |
| auto | aut**y** | Parking s auty. |
| okno | okn**y** | Dům s velkými okny. |
| pivo | piv**y** | S českými pivy. |

### Soft Neuter (-e nouns) → **-i**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| moře | moř**i** | Mezi moři. |
| pole | pol**i** | Za poli. |

### -í Neuter → **-ími**

| Nom. Sg. | Instr. Pl. | Example |
|:---------|:-----------|:--------|
| nádraží | nádraž**ími** | Mezi nádražími. |
| náměstí | náměst**ími** | S náměstími. |

## Common Mistakes

:::warning Watch Out!

**❌ Se studentami** (wrong ending!)
**✅ Se studenty** (masc. hard → -y)

---

**❌ S ženamy** (wrong ending!)
**✅ Se ženami** (fem. -a → -ami)

---

**❌ Mezi městami** (wrong ending!)
**✅ Mezi městy** (neut. -o → -y)
:::
