## The Golden Rule

:::tip Remember This!
| Gender | Singular | Plural |
|:-------|:---------|:-------|
| Masculine | **-em** | **-y/-i** |
| Feminine -a | **-ou** | **-ami** |
| Feminine -e/cons | **-í** | **-emi/-mi** |
| Neuter -o | **-em** | **-y** |
| Neuter -e/-í | **-em/-ím** | **-i/-ími** |
:::

## Instrumental Prepositions

| Preposition | Meaning | Example |
|:------------|:--------|:--------|
| **s/se** | with | Jdu s bratrem. |
| **před** | in front of, before | Stojím před domem. |
| **za** | behind | Auto je za domem. |
| **nad** | above | Lampa visí nad stolem. |
| **pod** | under | Kočka je pod stolem. |
| **mezi** | between | Sedím mezi nimi. |

## Quick Decision Tree

```
INSTRUMENTAL = HOW? WITH WHAT? WITH WHOM?

After s/se, před, za, nad, pod, mezi?
├── Yes → Use instrumental
└── No → Expressing means/tool (by what)?
    ├── Yes → Use instrumental (no preposition!)
    └── Expressing identity (být + profession)?
        └── Yes → Use instrumental
```

---

## The 2 Questions

1. **By what means/tool?** → Instrumental (no preposition)
2. **With whom? Where (location)?** → Instrumental (with preposition)
